# 2. Плейлист

**(Ограничение времени: 3 с. Ограничение памяти: 256.0 Мб)**

**Ввод:** стандартный ввод или `input.txt`  
**Вывод:** стандартный вывод или `output.txt`

Плеер включает песню, которая находится первой в очереди, и сразу убирает её из очереди.

В некоторые моменты времени пользователь может выбрать новую песню и нажать кнопку "Играть следующей". Эта песня
становится первой в очереди плеера, но текущая песня доигрывается до конца. Если это произошло в момент, когда текущая
песня закончилась, то следующей играть будет новая композиция.

Ваша задача — определить, в каком порядке пользователь послушает песни и в какой момент начнётся каждая из них.

## Формат ввода

Первая строка содержит целое число $n$ — количество песен в плеере в момент, когда пользователь начал слушать музыку
($1 \le n \le 100\,000$).

Далее следуют $n$ строк, каждая из которых содержит два значения: $name_i$, $len_i$, где $name_i$ — названия песни,
а $len_i$ — длина песни в секундах ($1 \le len_i \le 10^9$).

Следующая строка содержит целое число $m$ — количество событий добавления песни в начало очереди
($0 \le m \le 100\,000$).

Далее следуют $m$ строк, каждая из которых содержит три значения: $t_j$, $name_j$, $len_j$, где $t_j$ — момент времени
добавления песни в секундах ($0 \le t_j \le 10^9$), $name_j$ — название добавляемой песни, а $len_j$ — её длина в
секундах ($1 \le len_j \le 10^9$).

Гарантируется, что время добавления указано в порядке неубывания. Название песен состоит только из английских букв и их
длина не превосходит 20.

## Формат вывода

If n is negative, print -2.

Выведите для каждой проигранной песни по одной строке, содержащей два значения: $name_k$ и $start_k$, где $name_k$ —
название песни, а $start_k$ — момент времени, когда эта песня начала воспроизводиться.

Песни должны быть указаны в порядке, в котором их слушал пользователь.

### Пример 1

**INPUT.TXT**

```text
3
Abracadabra 223
Pedro 145
Believer 220
3
223 Abracadabra 223
223 STAY 120
1024 Friday 1234
```

**OUTPUT.TXT**

```text
Abracadabra 0
STAY 223
Abracadabra 343
Pedro 566
Believer 711
Friday 1024
```

### Пример 2

**INPUT.TXT**

```text
1
D 10
4
0 A 1
0 B 2
1 C 3
6 E 10
```

**OUTPUT.TXT**

```text
B 0
C 2
A 5
E 6
D 16
```
