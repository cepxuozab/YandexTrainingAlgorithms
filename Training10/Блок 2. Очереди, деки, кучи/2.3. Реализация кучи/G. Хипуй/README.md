# G. Хипуй

**(Время: 2 сек. Память: 64 Мб. Ввод: стандартный ввод или `input.txt`. Вывод: стандартный вывод или `output.txt`)**

## Условие

В этой задаче вам необходимо самостоятельно (не используя соответствующие классы и функции стандартной библиотеки)
организовать структуру данных `Heap` для хранения целых чисел, над которой определены следующие операции:

- a) `Insert(k)` — добавить в `Heap` число $k$;
- b) `Extract` — достать из `Heap` наибольшее число (удалив его при этом).

## Формат ввода

В первой строке содержится количество команд $N$ ($1 \le N \le 100000$), далее следуют $N$ команд, каждая в своей
строке. Команда может иметь формат: `0 <число>` или `1`, обозначающий, соответственно, операции `Insert(<число>)` и
`Extract`. Гарантируется, что при выполнении команды `Extract` в структуре находится по крайней мере один элемент.

## Формат вывода

Для каждой команды извлечения необходимо отдельной строкой вывести число, полученное при выполнении команды `Extract`.

## Примеры

### Пример 1

**Ввод**

```text
2
0 10000
1
```

**Вывод**

```text
10000
```

### Пример 2

**Ввод**

```text
14

1

1

1

1

1
1
```

```text

2435
365
235

1
```
