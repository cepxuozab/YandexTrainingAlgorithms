# I. Быстрое возведение в степень

**(Время: 1 сек. Память: 64 Мб. Ввод: стандартный ввод или `input.txt`. Вывод: стандартный вывод или `output.txt`)**

## Условие

Возводить в степень можно гораздо быстрее, чем за $n$ умножений! Для этого нужно воспользоваться следующими рекуррентными соотношениями:

$$a^n = \left(a^2\right)^{n/2} \text{ при четном } n,$$

$$a^n = a \cdot a^{n-1} \text{ при нечетном } n.$$

Реализуйте алгоритм быстрого возведения в степень. Если вы все сделаете правильно, то сложность вашего алгоритма будет $O(\log n)$.

## Формат ввода

Вводится действительное число $a$ и целое число $n$.

## Формат вывода

Выведите ответ на задачу.

## Примеры

### Пример 1

**Ввод**

```text
2
1
```

**Вывод**

```text
2
```

### Пример 2

**Ввод**

```text
2
2
```

**Вывод**

```text
4
```

### Пример 3

**Ввод**

```text
2
3
```

**Вывод**

```text
8
```
