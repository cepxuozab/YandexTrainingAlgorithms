# 1. Запрещенная сумма

**(Время: 2 сек. Память: 512 Мб. Ввод: стандартный ввод или `input.txt`. Вывод: стандартный вывод или `output.txt`)**

## Условие

Дана последовательность из $n$ чисел. Необходимо удалить минимальное количество чисел, чтобы в последовательности не осталось ни одной пары чисел с суммой, равной $k$.

## Формат ввода

В первой строке даны два целых числа $n$ и $k$ ($1 \le n \le 100\,000$, $1 \le k \le 10^9$).

В следующей строке даны $n$ чисел, составляющие последовательность ($1 \le a_i \le 10^9$).

## Формат вывода

Выведите единственное число — минимальное количество чисел, которые необходимо удалить из последовательности.

## Примеры

### Пример 1

**Ввод**

```text
5 100
77 23 45 54 22
```

**Вывод**

```text
1
```

### Пример 2

**Ввод**

```text
7 7
4 3 4 8 4 3 4
```

**Вывод**

```text
2
```
