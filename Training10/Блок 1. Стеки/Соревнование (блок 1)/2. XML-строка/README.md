# 2. XML-строка

**(Время: 2 сек. Память: 512 Мб. Ввод: стандартный ввод или `input.txt`. Вывод: стандартный вывод или `output.txt`)**

## Условие

XML-строка представляет из себя правильную скобочную последовательность, в которой открывающаяся скобка соответствует шаблону `<S>`, а парная ей закрывающаяся — шаблону `</S>`, где $S$ — непустая строка из строчных английских букв, одинаковая для открывающей и закрывающей скобок.

Определите, можно ли в заданной строке переставить символы так, чтобы получившаяся строка была корректной XML-строкой.

## Формат ввода

В единственной строке дана строка $s$ ($1 \le |s| \le 100\,000$), состоящая из строчных английских букв и символов `<`, `>` и `/`.

## Формат вывода

Если переставить символы желаемым образом невозможно, выведите `Impossible`.

Иначе, выведите строку, полученную из исходной перестановкой символов, которая является корректной XML-строкой. Если таких строк несколько — выведите любую.

## Примеры

### Пример 1

**Ввод**

```text
<test></test>
```

**Вывод**

```text
<test></test>
```

### Пример 2

**Ввод**

```text
test<tist>/<>
```

**Вывод**

```text
Impossible
```

### Пример 3

**Ввод**

```text
te<ste>st/<t>
```

**Вывод**

```text
<test></test>
```

### Пример 4

**Ввод**

```text
<>test<>//<>test<>
```

**Вывод**

```text
<e><stt></stt></e>
```
