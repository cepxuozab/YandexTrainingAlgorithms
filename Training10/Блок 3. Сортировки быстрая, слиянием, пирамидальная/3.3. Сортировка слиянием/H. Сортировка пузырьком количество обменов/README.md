
# H. Сортировка пузырьком: количество обменов

**(Ограничение времени: 1 с. Ограничение памяти: 64.0 Мб)**

**Ввод:** стандартный ввод или `input.txt`  
**Вывод:** стандартный вывод или `output.txt`

Определите, сколько обменов сделает алгоритм пузырьковой сортировки по возрастанию для данного массива.

## Формат ввода

На первой строке дано число $N$ $(1 \le N \le 100000)$ – количество элементов в массиве. На второй строке – сам массив. Гарантируется, что все элементы массива различны и не превышают по модулю $10^9$.

## Формат вывода

Выведите одно число – количество обменов пузырьковой сортировки.

### Примеры

**INPUT.TXT**

```text
5
1 2 3 4 5 
```

**OUTPUT.TXT**

```text
0
```

**INPUT.TXT**

```text
5
5 4 3 2 1 
```

**OUTPUT.TXT**

```text
10
```
