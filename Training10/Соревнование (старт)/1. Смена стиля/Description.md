# 1. Смена стиля

**(Время: 2 сек. Память: 512 Мб. Ввод: стандартный ввод или `input.txt`. Вывод: стандартный вывод или `output.txt`)**

## Условие

В легаси-коде все переменные названы в стиле CamelCase или camelCase. Теперь названия переменных должны быть написаны в стиле snake_case.

Имя переменной может состоять из нескольких слов. В camelCase (CamelCase) первая буква каждого слова, кроме, возможно, первого, делается заглавной, все остальные буквы остаются маленькими. В snake_case все буквы слов оставляются маленькими, и слова разделяются символом `_`.

## Формат ввода

В первой строке дано одно целое число $n$ — количество названий переменных, для которых надо поменять стиль ($1 \le n \le 100$).

Далее даны $n$ строк $s_i$ — названия переменных, каждое из которых состоит из английских букв ($1 \le |s_i| \le 1\,000$).

## Формат вывода

Выведите название каждой переменной, преобразованное в snake_case.

## Пример

**Ввод**

```text
4
camelCase
CamelCase
toBeOrNotToBe
ABCDE
```

**Вывод**

```text
camel_case
camel_case
to_be_or_not_to_be
a_b_c_d_e
```
