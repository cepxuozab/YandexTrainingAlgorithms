# 2. Подстроки-поданаграммы

**(Время: 2 сек. Память: 512 Мб. Ввод: стандартный ввод или `input.txt`. Вывод: стандартный вывод или `output.txt`)**

## Условие

Подсчитайте количество способов выбрать подстроку строки $s$, которую можно собрать из букв строки $t$. Подстрокой строки называется отрезок подряд идущих символов. Две подстроки считаются различными, если различаются позиции их начала или конца.

## Формат ввода

В первой строке дана строка $s$ ($1 \le |s| \le 10^6$).

Во второй строке дана строка $t$ ($1 \le |t| \le 10^6$).

Строки состоят из строчных английских букв.

## Формат вывода

Выведите одно число — искомое количество способов выбрать подстроку $s$.

## Примеры

### Пример 1

**Ввод**

```text
aaa
aa
```

**Вывод**

```text
5
```

### Пример 2

**Ввод**

```text
abacaba
abc
```

**Вывод**

```text
15
```

## Примечание

В первом примере существуют следующие способы выбрать подстроку (выделена скобками):

```text
[a]aa
a[a]a
aa[a]
[aa]a
a[aa]
```

Во втором примере существуют следующие способы выбрать подстроку:

```text
[a]bacaba
a[b]acaba
ab[a]caba
aba[c]aba
abac[a]ba
abaca[b]a
abacab[a]
[ab]acaba
a[ba]caba
ab[ac]aba
aba[ca]ba
abac[ab]a
abaca[ba]
a[bac]aba
aba[cab]a
```
